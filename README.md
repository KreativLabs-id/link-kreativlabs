# KreativLabs — Official Link Hub

Website Link Hub / Bio Link alternatif resmi untuk **KreativLabs** (`https://link.kreativlabs.id/`).  
Dibangun murni menggunakan **HTML5, CSS3, dan Vanilla JavaScript** tanpa framework eksternal, berfokus pada kecepatan muat tinggi, kejelasan informasi, dan optimasi SEO menyeluruh.

---

## Fitur Utama

- **100% Vanilla Tech Stack**: Tanpa React, Tailwind, atau build system yang rumit. Siap dijalankan langsung dengan membuka `index.html`.
- **Desain Otentik KreativLabs**: Mengadopsi palet warna resmi (`#2F4E60`, `#6995AD`, `#F8FAFB`) dan tipografi *Plus Jakarta Sans*.
- **Bootstrap Icons**: Menggunakan Bootstrap Icons resmi yang presisi, ringan, dan familiar.
- **Data-Driven Architecture**: Seluruh link dan profil media sosial dikonfigurasi melalui objek data di `script.js` sehingga mudah diperbarui.
- **SEO & Social Share Ready**:
  - Open Graph (WhatsApp, Facebook, LinkedIn) dengan banner resmi (1200×630px).
  - Twitter / X Card `summary_large_image`.
  - Schema.org (JSON-LD) terverifikasi untuk Google Rich Results.
  - `robots.txt` dan `sitemap.xml` terkonfigurasi untuk domain `https://link.kreativlabs.id/`.
  - Dukungan PWA / Web App via `site.webmanifest`.

---

## Struktur File

```
link-kreativlabs/
├── index.html            # Halaman utama dengan markup semantik & meta SEO lengkap
├── style.css             # Desain sistem responsif (mode terang)
├── script.js             # Data-driven links & smart share logic
├── robots.txt            # Panduan perayap mesin pencari
├── sitemap.xml           # XML sitemap untuk Google Search Console
├── site.webmanifest      # Konfigurasi PWA / Web App
├── .gitignore            # Filter file cache & editor
└── assets/
    ├── logo.png          # Logo profil KreativLabs
    ├── favicon.png       # Favicon browser multi-ukuran
    ├── logo-white.png    # Aset logo teks putih
    └── og-image.png      # Banner pratinjau media sosial (1200x630)
```

---

## Menjalankan Proyek

Buka file `index.html` langsung di browser, atau jalankan menggunakan ekstensi **Live Server** di VS Code.
